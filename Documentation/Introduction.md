# Introduction

**Bim.FamilyManager** is an advanced add-in for Autodesk® Revit® (2025 and newer) designed to centralize and streamline the management, organization, and deployment of Revit family files. It enables users to browse, preview, and load families from multiple sources—including local directories and Azure cloud storage—directly within the Revit environment.

With a modern, user-friendly interface, Bim.FamilyManager supports drag-and-drop, batch operations, metadata management, and extensibility for custom sources. The tool is ideal for architects, engineers, and BIM managers who need efficient access to family libraries, versioning, and seamless integration with Revit workflows.

**Key Features:**
- Centralized management of Revit families from local and cloud sources
- Family and type preview images
- Drag-and-drop loading into projects or the family editor
- Batch operations and metadata/version tracking
- Extensible architecture for custom storage providers and UI themes
